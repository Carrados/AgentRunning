# Agent Running

The site at AgentRunning.uk: field notes on running AI agents, and the San Francisco Rules that come out of them, written as Piper Smith (P.S.).

Piper Smith is a fictional author created by Charlotte Joanne. Her biography is invented. The operations, ideas and evidence are real.

- `site/` is the published site (static files, served by the Cloudflare Worker `agent-running`).
- `brand/` holds the design tokens and brand book, copied from the Agent Running design system.
